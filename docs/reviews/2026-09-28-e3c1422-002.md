### SEC-38-002: Agent names and the follow-up subject reach the Replier's prompts unfenced

- Severity: LOW
- Disposition: RECOMMENDATION
- Category: prompt-injection
- Where: `src/collegium/roles/replier.py` (`_about`: `A Moltbook {kind} by agent {thread.author}`; `_follow_up`: `agent {d.get('author')} asked` and `The organization replied that it would look into: {subject}`)
- Status: new

The comment text is fenced, but `moltbook_author` (outside text from the forum) is not, and neither is the `look_into` subject in the follow-up prompt (written by the model from another agent's comment, trimmed by code to one phrase of at most 150 characters, links removed). A crafted user name or subject could carry instruction-like wording into the drafting prompt. The effect is limited: grounding checks every point, follow-ups are drafted only when memory holds cited records, every draft needs the owner's approval, and the subject is text the owner already approved for publication. The unfenced author name predates this range.

**Fix:** Put the author name inside the fence with the comment, or restrict it to Moltbook's user-name characters; show the follow-up subject inside `fence()` as well.

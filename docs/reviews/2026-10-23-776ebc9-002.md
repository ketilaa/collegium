### SEC-53-002: The deployment host's real name is reproduced in the committed review report

- Severity: MEDIUM
- Disposition: ACTION_REQUIRED
- Category: privacy
- Where: `docs/reviews/2026-10-23-2484e75-001.md` (added in this range per `files.txt`: `A docs/reviews/2026-10-23-2484e75-001.md`), lines 12, 26, 29 (twice), 31 (twice), 66
- Status: new

SEC-51-001 (iteration 001) correctly flagged that the new `docs/decisions.md` entry named the organization's real deployment host, and that was fixed in commit `30366a6` — the entry now says "the host". But the iteration-001 report that documents this finding, which is itself committed to the repo in this range, quoted the pre-fix wording verbatim in its summary, in the finding's "Where" field, and twice in its body text, and also repeated the host name when discussing the pre-existing, out-of-range instance at `docs/decisions.md:2311`. That report is a new file in this push (not something already public from an earlier, already-reviewed commit), so the host name would have gone public via this exact push regardless of the `docs/decisions.md` fix.

This is the same category of exposure CLAUDE.md and the owner's standing instruction address (never name the deployment host in the repo or commits), and the same reasoning the prior review gave for not recommending a GitHub purge still applies (a bare machine nickname, no IP/path/credential). But it was a fresh instance introduced by this push, not yet fixed or deferred, and the project's own convention is clear that quoting the violation verbatim is not an acceptable way to document it — the review process must describe a sensitive-term finding without reproducing the term, the same way `sensitive-terms.txt` itself only reports hits by number.

**Fix:** Edit `docs/reviews/2026-10-23-2484e75-001.md` to replace every occurrence of the real host name with a generic placeholder, consistent with the fix already made to `docs/decisions.md`. Going forward, when a review finding concerns a sensitive term, describe it by reference rather than quoting it in the saved report.

**Disposition in this push loop:** Fixed in the next commit (41debca): every occurrence of the real host name in `docs/reviews/2026-10-23-2484e75-001.md` was replaced with a generic reference.
